# Beauty - Dicas de Maquiagem, Pele e Cabelo

## Sobre o Projeto

Beauty é um site criado para compartilhar dicas de maquiagem, cuidados com a pele e cuidados com os cabelos. O objetivo é ajudar pessoas que desejam aprender mais sobre autocuidado e conhecer produtos que podem contribuir para sua rotina de beleza.

O site possui categorias separadas para facilitar a navegação e a busca por conteúdos relacionados a pele, cabelo e maquiagem.

## Funcionalidades

* Página inicial com apresentação do site.
* Categoria de Pele com sugestões de produtos e cuidados.
* Categoria de Cabelo com produtos e tratamentos capilares.
* Categoria de Maquiagem com recomendações e avaliações de produtos.
* Layout moderno e responsivo.
* Avaliações e descrições dos produtos apresentados.

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
